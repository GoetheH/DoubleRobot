# 霓虹突围（NEON BREAKOUT）

**可视化编辑入口：Unity菜单「霓虹突围 → 关卡工作台」。** 八关现已保存为真实Prefab，平台/出生点/出口/道具/机关可在Scene拖动，战斗参数与图片可在Inspector调整。具体步骤见 [Unity可视化编辑指南](Unity可视化编辑指南.md)。

## 获取与版本控制

源码仓库：https://github.com/GoetheH/DoubleRobot 。正式游戏名为“霓虹突围（NEON BREAKOUT）”，仓库地址保留原名称。克隆仓库后，在 Unity Hub 中添加仓库内的 `UnityProject/` 文件夹，使用 Unity 2022.3.62f3c1 打开；编辑器菜单 `霓虹突围 → 运行游戏` 可启动。当前目录结构将Unity工程放在 `UnityProject/`，旧版提交仍保留在Git历史中。

版本库包含 `Assets`（含meta与原创背景）、`Packages`、`ProjectSettings`、说明、美术生成记录、选定实机截图及当前自动验证报告。Unity缓存、日志、用户设置、原始压缩包和本机试玩构建不提交；从GitHub克隆后需自行构建试玩程序。

在仓库根目录运行 `git status` 查看改动，使用 `git add`、`git commit` 提交后，运行 `git push origin main` 同步。不要单独删除或忽略Unity资源的 `.meta` 文件。

运行 `试玩版/NeonBreakout.exe`。同目录的 `NeonBreakout_Data`、`MonoBleedingEdge` 和 DLL 必须保留。原始试玩和原始源码压缩包保存在 `原始压缩包/`。

本地交付压缩包为 `霓虹突围-Windows试玩.zip` 与 `霓虹突围-Unity源码.zip`，不纳入Git历史。

在 Unity 中打开 `UnityProject/` 后，选择菜单 `霓虹突围 → 运行游戏`，即可自动打开 Main 场景并进入 Play 模式。Game 视图聚焦时按 Shift+Space 可切换最大化。

八关已统一为赛博朋克像素美术：第一关雨夜城市、第二关橙红熔炉、第三关冷蓝安保反应厅、第四关雷雨天线高塔、第五关青绿数据机房、第六关工业配电站、第七关深绿地下档案、第八关紫红中枢反应堆。四职业关节动作、守卫、无人机和五类枪械在全部关卡使用新外观；两场Boss使用新悬浮装甲守卫。方向、资产和生成提示词见 `美术样板/全关卡美术记录.md`，实机截图见 `验证/campaign-2.png` 至 `验证/campaign-8.png`。

## 出击准备

首页点击“开始游戏”，依次进入三个独立页面：难度选择 → 职业选择 → 枪械选择。每页提供介绍、当前选择、返回和下一步；职业页可预览人物及技能特效，枪械页可查看独立枪械外形、定位与参数。只有枪械页“确认配置并出击”才会开始战斗。Enter前进，Esc返回；返回上一步保留已选内容。

## 职业

开始页面同时提供简单、中等、困难三档难度，默认中等。选择后点击开始，本局全程使用该难度；关间升级和结算重开保留选择，返回主菜单可重新设置。HUD与结算界面会显示本局难度。

| 难度 | 敌人生命 | 敌人伤害 | 攻击间隔 |
| --- | --- | --- | --- |
| 简单 | 75% | 70% | 125%（更慢） |
| 中等 | 100% | 100% | 100% |
| 困难 | 135% | 135% | 80%（更快） |

普通敌军与Boss均使用以上倍率，伤害取整。三档难度下的地图、职业技能、枪械与通关任务相同。

在主菜单选择职业、携带枪械与难度，再点击开始；每个职业都能在局外选择任意一类枪械。

四种职业在全部关卡和职业选择页使用不同的义体人形：突击兵围巾与护甲、医疗兵白绿医疗背包、工程师黄铜装具、侦察兵紫色披风。跑动摆腿、跳跃收腿，围巾与衣摆随动作摆动。技能分别显示双枪与旋转超载环、治疗波与医疗十字、炮台部署网格、紫色雷达与敌人弱点锁定框。职业选择页提供动态预览，局内由真实技能触发，并随暂停冻结。

| 职业 | Q技能 | 冷却 |
| --- | --- | --- |
| 突击兵 | 双枪过载5秒：幻化当前枪械的副本，两个枪口同步射击 | 12秒 |
| 医疗兵 | 回复40装甲，获得2秒无敌 | 14秒 |
| 工程师 | 部署持续8秒的自动索敌炮台 | 15秒 |
| 侦察兵 | 弱点扫描：标记14米内现有敌人6秒，对标记目标的枪械伤害+50%；基础移动更快 | 6秒 |

弱点扫描可标记Boss，标记跟随目标；新出现或施放时在范围外的敌人不会自动被标记。所有五类携带枪械均可增伤，伤害取整；机枪过热、霰弹距离衰减等特性保留。标记结束恢复正常伤害，自动炮台不享受增伤。扫描不改变位置、速度或无敌时间，Shift/右键冲刺仍可正常使用。

## 枪械

双枪过载适用于全部五类枪械，保持各自的射击间隔与特性。霰弹枪同时发射两组弹丸，狙击枪同时发射两发穿透弹；机枪同时累积两把枪的热量。过载结束后恢复单枪。

出击前从五类枪械中选择一把。本局八关固定使用该枪械，数字键与滚轮均不会切枪；关间升级只强化携带枪械。结算后直接重开沿用选择，返回主菜单后才能换枪。战斗HUD只显示本局携带枪械及其状态。

五类枪械各有独立像素模型：步枪的能量匣、霰弹枪的双管与泵柄、狙击枪的长磁轨与瞄准镜、机枪的散热护罩与弹鼓、冲锋枪的短管与折叠枪托。局内持枪随准星旋转，并显示后坐、各自的枪口闪光及弹道；子弹从对应枪口位置发射。

持枪及特效线条的旋转使用画布内的局部坐标，支持窗口缩放和非16:9黑边。`验证/瞄准回归/`记录了1280×720、1024×768下五把枪的四向截图及狙击枪斜向截图；矩阵断言覆盖6种窗口尺寸、300个旋转姿态的握持点和边界。

| 序号 | 枪械 | 特性 |
| --- | --- | --- |
| 1 | 脉冲步枪 | 精准稳定，射击间隔0.145秒，单发16伤害 |
| 2 | 裂片霰弹枪 | 7发弹丸，42°散射，0.65秒间隔，弹丸13基础伤害随距离衰减 |
| 3 | 磁轨狙击枪 | 单发100伤害，穿透多个敌人，高弹速，1.05秒间隔 |

## 八关流程

第1—7关通过传送门后选择一个升级，第3关击败Boss后继续后续剧情。

| 关卡 | 地图与任务 | 出口 |
| --- | --- | --- |
| 1 霓雨下城 | 雨夜城市美术样板，横向清除敌军 | 右侧接驳电梯 |
| 2 熔炉生产线 | 平台战斗，清除敌军 | 右侧 |
| 3 核心守卫 | 击败守卫，两阶段弹幕 | 右侧 |
| 4 天线高塔 | 32米纵向地图，二段跳攀登，收集天线钥匙 | 塔顶 |
| 5 数据回收 | 收集三份数据，回程仍有敌军 | 左侧起点 |
| 6 配电迷阵 | 按提示顺序 II → I → III 接通三个机关，错误重置 | 地图中部 |
| 7 地下档案 | 从高层下行，收集两份档案 | 底部左侧 |
| 8 中枢停机 | 击败强化守卫，并按顺序关闭反应堆，两项完成后立即显示胜利结算 | 自动结算，无需进入传送门 |

第4—7关无需消灭全部敌人；HUD显示任务、进度、传送门方向和距离。道具接触领取，机关靠近按E。天线钥匙、数据芯片、封存档案有各自标识；机关按实际接通进度变色，输错顺序后恢复未接通状态。平台顶边使用明亮边线，和背景设施区分。所有职业都可以完成机关与路线。

第8关两项目标可以按任意先后顺序完成。只击败守卫时，顶部会提示继续关闭反应堆；只关闭反应堆时，会提示击败守卫。两项完成后战斗停止，显示“通关成功”、积分、击破、最高连击、职业与用时。结算后按R重新出击，或按Esc返回主菜单重新选择职业；不会进入第9关。

## 操作

A/D移动，Space或W二段跳，S穿过平台下落，鼠标瞄准、左键射击，Shift或右键冲刺，Q职业技能，E机关交互，Esc暂停，M切换声音，R结算后重开。数字键1—3只在关间补给页面选择升级。

## 源码与构建

`UnityProject/` 使用 Unity 2022.3.62f3c1。关卡来自 `Assets/Resources/Authoring/Levels/` 下的八个Prefab，战役和数值来自 `Campaign.asset`、`Balance.asset`；人物、枪械与敌人图片保存在 `Authoring/Art/`，运行时直接加载。原先的代码绘图仅保留在编辑器首次迁移工具中。已移除旧双人竞技模式；动画、战斗行为与HUD继续由脚本驱动，布局与常用数值可通过Unity编辑器修改。

运行 `构建.ps1` 可重新构建。当前机器的Unity包管理器初始化报错，构建使用 `-noUpm` 与已验证的本机缓存；该脚本会明确检查构建结果。标准Unity环境可以正常通过编辑器打开工程。

`验证/` 内包含运行断言结果和实际截图。覆盖五枪发射命中、狙击穿透、机枪过热冷却、四职业技能与冷却、炮台索敌、伤害无敌、升级、Boss弹幕、所有任务门锁与出口、失败重开。纵向地图额外检查相邻平台高度与二段跳上升能力；自动验证不等同于完整人工通关和手感评测。

本轮额外验证：八关背景及新Boss资源加载、机关部分接通/错误重置/全部接通显示、五枪过载弹数翻倍、双枪口独立位置、成对弹丸实际伤害、原射击间隔和技能结束恢复单枪；保留六种窗口尺寸、300种旋转姿态的瞄准回归。`campaign-*.png` 与 `slice-*.png` 为实际Windows构建的自动布景截图，另有塔顶出口、地下档案底层出口和配电完成截图。

可编辑性额外验证包括Prefab位置/尺寸修改后的保存与重新载入，以及实际运行中布局、道具数量、机关顺序、枪械/技能/难度配置的生效。报告见 `验证/authoring-validation.txt` 和 `验证/runtime-validation.txt`。构建会检查关卡及配置，发现缺失出生点、出口、重复机关编号等问题时终止并报告错误。
