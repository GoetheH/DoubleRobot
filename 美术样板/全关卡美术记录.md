# 八关赛博朋克美术更新

延续第一关“霓雨下城”的像素义体人物与金属材质，将第2—8关统一至相同表现。保持原地图碰撞、敌人行为、难度倍率、道具位置和通关条件。

| 关卡 | 美术与识别设计 |
| --- | --- |
| 2 熔炉生产线 | 橙红炉膛、输送设施、管道和上升余烬 |
| 3 核心守卫 | 冷蓝安保反应厅、新悬浮装甲守卫和核心光圈 |
| 4 天线高塔 | 冷蓝雷雨天际、纵向塔柱与斜撑、塔顶钥匙与升降舱 |
| 5 数据回收 | 青绿服务器阵列、悬浮数据芯片、左侧数据回程舱 |
| 6 配电迷阵 | 冷色工业配电站、金色平台边线、线路与独立终端，依次显示已接通状态 |
| 7 地下档案 | 深绿地下机柜、分层库房编号、封存档案与底层撤离舱 |
| 8 中枢停机 | 紫红反应堆、装甲守卫核心、终端与既有即时结算流程 |

四职业在全部关卡使用新关节动作、围巾/背包装具；侦察兵现使用弱点扫描技能，显示紫色雷达与敌人锁定框。新增霰弹枪双管泵柄、机枪散热护罩和弹鼓、冲锋枪折叠枪托细节，五种枪械外观现已全部更新。两场Boss使用同一新装甲模型，通过场景和核心色区分，狂暴阶段核心转为橙色。

新增4张原创背景，通过内置 **image_gen** 工具分别生成，保存至 `UnityProject/Assets/Resources/ArtSlice/`：`Foundry.png`、`Spire.png`、`Archive.png`、`Reactor.png`。第3/8关共享反应厅原图，第5/7关共享档案原图，第2/6关共享工业原图，代码叠加各自设施、灯光与色调。背景使用Point过滤，无mipmap；人物、设施、枪械与任务道具由代码生成。

验证截图来自实际Windows构建的自动布景，包含第2—8关、纵向地图上中下部、机关部分/全部激活、更新后的枪械及结算界面；自动验证不等同于完整人工通关和手感评测。
