## 上一版制作规划 R2

正式文档是 [Excel 工作簿](../outputs/neon-gdd-20261017/霓虹突围-游戏策划案.xlsx)。R2 编制于 2026-10-17，游戏规则基线为 1.1.1，对应功能提交 `1438d963fa8479d4e63a0555352092d4e74108a1`。文档修订没有改变游戏版本。

R1 是功能与数值清单。R2 增加制作过程所需的输入、输出、交接与验收信息：

- M0 至 M5 的进入条件、交付物、评审门禁和失败处置。签署人、日期、结论和证据均需真实填写。
- 战斗触发与处理顺序、冷却边界、无敌、弹道、掉落、刷怪、升级及结算异常分支。
- 八关 34 个分段节拍，附实际 Prefab 出生、出口、道具与机关位置。体验打磨布置与当前动态刷怪分开标注。
- 31 项资源订单、当前 24 张持久 PNG 的尺寸、源文件交付与入库标准。
- 30 项制作任务，包含岗位、前置依赖、完成定义、三点工时估算、负责人、验收人和证据字段。
- 42 项具体回归用例、60 个职业枪械难度入口组合、设备性能记录和缺陷分级。完整配装关卡空间为 480 个场景，入口验证不冒充全战役验证。
- 根据可用产能与费率计算岗位负荷和成本。未提供的输入保持空缺，不输出虚假工期。
- 发布构建、容量、历史版本、上线验证、回滚与补丁处理，以及待决策事项。

阅读时先看「版本立项」「开发里程碑」「调研与决策」，再按需求、资源、任务、测试编号评审。黄色字段可填写或调参，公式结果随输入更新。表格不会自动回写 Unity。

所有新制作任务初始为未启动，测试为未执行。工时、设备目标、用户测试样本和新增功能是评审草案，并非已经批准的承诺或已完成的实测。现有工程自动验证记录仅是历史依据。

`策划案-R2审阅快照.jsonl` 是正式工作簿的逐行内容与公式快照，便于在 Git 中审阅文字和规则差异。它不是第二份独立策划源文件；编辑正式文档后应同步快照，避免相互矛盾。

本轮仅验证了策划案公式、依赖关系、导出内容和排版，未重新执行游戏构建或通关测试。Unity 与 Xbox 的公开流程/无障碍参考链接已列在工作簿「配置与依据」中。
