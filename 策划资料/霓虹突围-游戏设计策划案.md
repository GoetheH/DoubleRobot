# 《霓虹突围（NEON BREAKOUT）》游戏设计策划案

文档版本：R3 · Markdown 评审稿  
编制日期：2026-10-17  
适用范围：单人试玩版，四职业、五类枪械、三档难度、八个关卡。

本文按“设计概述、定义名词、功能设计、交互 UI 设计”组织，用于讨论游戏如何游玩、规则如何运转、界面如何表达。文中的数值以当前 1.1.1 工程为基线。

**状态说明：**“现行规则”表示可从当前配置或逻辑确认的行为，不代表本轮重新实机验收；“设计补充”表示本稿提出、尚需落实的体验设计。本文不修改游戏程序，也不将设计补充写成已完成成果。

## 一、设计概述

### 1.1 游戏定位

《霓虹突围》是一款以赛博朋克未来之城为背景的单人 2D 平台动作射击游戏。玩家在出击前确定难度、职业和携带枪械，进入城市封锁区，利用跳跃、冲刺、枪械和职业技能完成连续八关任务。

游戏的主要选择来自两个层面：出击前决定“用什么打法”，进入关卡后决定“如何用这套打法完成目标”。一局中不能更换枪械，玩家需要用同一把枪处理横向交战、向上攀登、往返收集、机关解谜、向下探索和 Boss 战。

关卡目标不统一为清敌。玩家应逐渐形成这样的判断习惯：**先看本关任务，再决定交战、绕行或交互，最后前往正确的出口。**

### 1.2 世界背景与行动动机

**现有背景：**雨夜废城、核心失控；玩家选择机体和武装，穿过八个区域的封锁。

**设计补充：**将八关组织成一次关闭城市失控中枢的行动。玩家先突破外围防线，击败区域守卫；随后取得通信钥匙、回收数据、接通配电、进入地下档案区，最终关闭反应堆。叙事通过关卡开场短句、任务名称和环境标识传达，不增加打断战斗的长对话。

每关任务都应回答两个问题：玩家来这里做什么；完成后为何要去下一区域。剧情不改变任务判定，也不把新增剧情文本视为现有内容。

### 1.3 目标体验

| 体验目标 | 玩家能够感知的结果 | 对应设计约束 |
| --- | --- | --- |
| 职业有明确区别 | 同一把枪搭配不同职业，会出现不同的技能使用时机 | 双枪爆发、急救保护、炮台支援、弱点扫描分别承担不同作用 |
| 枪械有取舍 | 选枪时能说明其优势和代价 | 不只调整伤害，还通过散布、穿透、距离衰减、热量和移速形成差异 |
| 路线具有变化 | 下一关不只是换背景后继续向右走 | 保留攀塔、回程、下行和中部出口；出口指引跟随实际位置 |
| 任务清楚 | 玩家知道还缺什么，而非在门前猜条件 | 收集数量、机关进度、Boss 与终关双目标分别表达 |
| 操作反馈直接 | 能区分技能是否成功、枪是否过热、机关为何失败 | 状态文字、轮廓、动作、音效共同表达，不只依赖颜色 |
| 内容可以人工调整 | 策划能改平台、目标位置和常用数值 | 关卡布局与数值保存在 Unity 可编辑资源中 |

### 1.4 核心游玩循环

```text
开始游戏 → 选择难度 → 选择职业 → 选择枪械 → 确认出击
                                              ↓
                         阅读任务 → 战斗 / 移动 / 收集 / 机关
                                              ↓
                         第 1—7 关：任务完成 → 到达出口
                                              ↓
                                  三选一补给 → 下一关

第 8 关：击败核心守卫 + 关闭反应堆 → 直接胜利结算
任意战斗关：生命耗尽 → 失败结算
结算：沿用配置重新出击，或返回首页重新选择
```

关间补给改变本局能力，但不改变携带枪械类别。重开后清空本局强化，从第一关重新开始。

### 1.5 美术方向

采用有层次的像素动作画风，以未来都市、工业设施和电子设备表现赛博朋克背景。参考《死亡细胞》的方向是角色剪影清晰、前后景层次明确、动作反馈有力度；人物、场景、枪械和标识使用本作原创设计。职业技能参考《元气骑士》中“技能改变短时间打法”的思路。

**设计补充的执行要求：**

- 背景以深蓝、灰紫和低亮度霓虹构成，减少与敌弹、角色和交互物争夺注意力。
- 可站立平台具有连续、清楚的上边缘；装饰线条不能被误认为平台。
- 突击兵突出厚重护肩与双枪轮廓，医疗兵突出医疗背包和十字标识，工程师突出工具臂与工程装备，侦察兵突出轻装与扫描设备。
- 步枪、霰弹枪、狙击枪、机枪、冲锋枪在枪管长度、枪托、弹匣和体积上区分，缩小到实际游戏尺寸后仍可辨认。
- 扫描、治疗、部署、双枪分别使用锁定框、十字粒子、部署网格、第二枪口等形状语言；颜色作为辅助。
- 技能特效不持续遮挡角色脚下的平台边缘、敌弹和机关编号。

### 1.6 本稿范围

本稿覆盖出击准备、基础动作、职业、枪械、战斗、关卡任务、关间强化、结算和相关 UI。不在本稿扩展联网合作、付费、装备仓库、持久成长树或局中存档。

当前支持 Windows 与 WebGL 试玩。本稿以键鼠交互为基准；移动端触控与手柄完整操作方案需要单独设计。

## 二、定义名词

后文统一使用以下名称。同一概念不在不同页面更换叫法。

| 名词 | 定义 | 使用边界 |
| --- | --- | --- |
| 一局 | 从确认出击，到胜利、失败或主动返回首页的一次完整尝试 | 一局最多推进八关；重开属于新的一局 |
| 局外 | 首页及难度、职业、枪械选择流程 | 本稿不把它扩展为仓库或养成大厅 |
| 局内 | 本局开始后的战斗与关间补给阶段 | 暂停保留本局状态；返回首页结束本局 |
| 关卡／区域 | 八关战役中的一个独立任务空间 | UI 显示“序号 / 关卡名”，两词指同一内容 |
| 职业 | 决定角色外观、移动参数和主动技能的出击选项 | 四职业均能选择全部五类枪械 |
| 职业技能 | 按 Q 施放的职业专属能力 | 与通用冲刺独立，不共用冷却 |
| 通用冲刺 | 所有职业都具备的短距离水平高速移动 | 用于位移与避伤，不是侦察兵专属技能 |
| 携带枪械 | 在局外选择、整局固定使用的枪械 | 关间强化不改变它的类别 |
| 一次射击 | 满足射击间隔后，从一个枪口发射一组弹丸 | 霰弹枪一次射击产生多枚弹丸；双枪有两个枪口 |
| 弹丸 | 独立移动、命中并计算伤害的子弹实体 | 单次射击伤害不能直接等同于单枚弹丸伤害 |
| 射击间隔 | 同一武器连续两次射击之间的最短时间，单位为秒 | 越小射得越快；不把“间隔减少”写成相同百分比的“射速增加” |
| 散布 | 弹丸偏离瞄准方向的范围 | 霰弹扇形角度与随机散布分别定义 |
| 穿透 | 弹丸命中一个敌人后仍能继续飞行并命中其他敌人 | 不代表当前另有墙体穿透判定 |
| 距离衰减 | 弹丸飞行距离增加时，其命中伤害下降 | 当前用于裂片霰弹 |
| 热量／过热 | 机枪射击积累的资源，以及达到阈值后暂时不能射击的状态 | 不等于弹药；其他枪械不显示热量条 |
| 生命／装甲完整度 | 同一生存数值；生命为 0 时失败 | 本稿玩家文案优先用“装甲”，公式用“生命”；不是两层血条 |
| 无敌时间 | 指定时间内不扣除生命的状态 | 冲刺、受伤保护、医疗技能分别触发；不意味着敌弹消失 |
| 冷却 | 从技能成功施放到允许再次施放的时间 | 从按 Q 成功触发时开始计算，不从效果结束时计算 |
| 持续时间 | 技能效果保持有效的时间 | 与冷却可以重叠；两者必须分别显示 |
| 扫描标记 | 侦察兵施放时，对范围内现有敌人施加的弱点状态 | 不自动标记之后生成的敌人 |
| 任务道具 | 被拾取后增加本关任务进度的物件 | 与回复生命的掉落物不同，不进入持久背包 |
| 机关／终端 | 玩家靠近后按 E 激活、参与顺序判定的交互物 | 编号表示终端身份，不等于默认激活顺序 |
| 出口／传送门 | 非终关任务完成后，玩家前往以结束当前关卡的位置 | 任务完成不等于自动传送；第八关另用自动结算 |
| 任务完成 | 本关配置规定的条件成立 | 收集关和机关关不附加清敌要求 |
| 关间补给／模块 | 第 1—7 关结束后，从三项候选中选择的一项本局强化 | 无需购买；本局有效，重开清空 |
| 连击 | 在限定时间内连续击杀、且未受伤的击破链 | 与“击中次数”不同；积分倍率有上限 |
| 最高纪录 | 本机保存的历史最高积分 | 不是云存档，也不能用来恢复中断的一局 |

## 三、功能设计

### 3.1 出击准备（F01）

**目的：**让玩家在开始承受战斗压力之前，理解并确定本局打法。

**现行规则：**

1. 从首页依次进入难度、职业、枪械选择页；每页只完成一种主要选择。
2. 每类选项均为单选。点击选项更新当前选择，不直接进入下一页。
3. 点击“下一步”或按 Enter 推进；Esc 返回上一页，保留当前选择。
4. 枪械页点击“确认配置并出击”后，才建立新的一局。前面的页面不运行关卡计时，不生成敌人，不消耗技能。
5. 难度初始为中等；职业与枪械的初始索引均为第一项。运行期间返回菜单时保留选择；不将这种保留描述为跨启动存档。
6. 正常战役从第一关开始：生命和最大生命为 100，积分、击破、连击及强化等级清零。
7. 职业、难度和枪械在局内锁定。返回首页后可以重新选择。

**设计补充：**确认出击按钮在提交后立即停止响应，防止连续点击导致多次初始化。底部始终显示当前三项配置摘要；修改前一页选项不清空后续选择。

### 3.2 难度（F02）

**目的：**通过战斗容错和敌人压力区分挑战，不让低难度玩家失去关卡内容。

| 难度 | 敌人生命倍率 | 敌人伤害倍率 | 敌人攻击间隔倍率 | 玩家介绍文案 |
| --- | ---: | ---: | ---: | --- |
| 简单 | 0.75 | 0.70 | 1.25 | 敌人更脆弱，伤害更低，攻击更慢，适合熟悉操作与任务。 |
| 中等 | 1.00 | 1.00 | 1.00 | 标准战斗体验，兼顾战斗、移动与任务推进。 |
| 困难 | 1.35 | 1.35 | 0.80 | 敌人更坚韧、伤害更高、攻击更频繁，适合熟练玩家。 |

倍率同时适用于普通敌人与 Boss。攻击间隔倍率小于 1 表示攻击更频繁；例如基准间隔 1.8 秒，在困难下为 1.44 秒。难度不改变任务道具数量、机关答案、出口位置和可选职业枪械。

不得把困难攻击间隔 80% 直接写成“攻击速度 +20%”；其频率提升为 25%。选择页优先显示“攻击间隔 80%（更快）”。

### 3.3 移动、跳跃、冲刺与瞄准（F03）

| 操作 | 现行规则 | 边界说明 |
| --- | --- | --- |
| A / D | 左右移动；一般职业基础速度 7.4，侦察兵 8.6 单位/秒 | 机枪额外乘约 0.85135 移速系数；一般职业持机枪约为 6.3 |
| Space / W | 最多二段跳；落地重置跳跃次数 | 跳跃初速度 10.6，重力 27；有 0.12 秒输入缓冲、0.1 秒离台容错 |
| S | 下穿单向平台 | 不穿过关卡底部实体边界；用于向下探索 |
| 左 Shift / 鼠标右键 | 冲刺速度 23，持续 0.17 秒，基础冷却 1.35 秒 | 有左右移动输入时按输入方向冲刺，否则按瞄准方向的水平朝向冲刺；不是自由八方向冲刺 |
| 鼠标移动 | 改变枪口瞄准方向 | 不要求角色移动才能转向 |
| 鼠标左键 | 按住连续射击，受武器间隔与过热限制 | 无需连续点按；不消耗弹药、不装填 |

冲刺提供对应时段的伤害保护。各职业共用这套移动操作，侦察兵的 Q 不再承担第二套位移。

**设计补充——瞄准表现约束：**枪械围绕角色持枪点旋转，翻向左侧时仍与持枪点连接。角色位于画面中央时，将鼠标绕角色完整移动一圈，枪械不得因错误中心点、翻转或相机偏移突然脱离角色。枪口火光和子弹起点跟随实际枪口；双枪分别校验两个起点。

### 3.4 职业与技能（F04）

#### 3.4.1 技能共通规则

- 仅在战斗进行中、冷却结束后允许按 Q 施放。冷却中按 Q 不改变现有冷却，也不重复产生效果。
- 技能成功触发时立即开始冷却；即使本次没有有效目标，仍然消耗冷却。
- 暂停时，技能持续时间和冷却均冻结。
- 进入下一关时清除上一关的技能实体和临时状态，职业技能与冲刺恢复可用；关间不能预先部署炮台或施放扫描。
- 死亡、重开、返回菜单后，上一局技能不得继续造成伤害或保留标记。

#### 3.4.2 突击兵：双枪过载

**定位：**在短时间内集中输出，适合围绕 Boss 露出机会或敌群集中时施放。

**现行规则：**持续 5 秒，冷却 12 秒。复制当前携带枪械形成第二把枪，两处枪口同步按该枪的射击规则发射。使用霰弹枪时两把枪分别发射各自的弹丸组；使用狙击枪时两个枪口分别发射穿透弹。

双枪不是改成另一类武器。机枪双枪同时增加两个枪口的热量，过热会限制持续输出，不能把双枪效果写成“五秒内无条件两倍总伤害”。效果结束恢复单枪。

**视觉与 UI 要求：**橙色能量强化轮廓、明确的副枪模型、两处独立枪口火光。显示“双枪过载”及剩余持续时间；冷却另行计算。

#### 3.4.3 医疗兵：应急修复

**定位：**通过恢复和短暂保护，提高受压时的存活能力。

**现行规则：**立即回复 40 点生命，不超过最大生命；获得 2 秒无敌，冷却 14 秒。满血时也允许施放，回复部分溢出，但仍获得无敌并消耗冷却。技能不提升最大生命，不治疗炮台，也不提供队友治疗功能。

**视觉与 UI 要求：**绿色扩散治疗波、上升十字、短暂保护轮廓。生命变化与实际回复量一致；满血施放不能显示虚假的“+40”实际恢复。

#### 3.4.4 工程师：部署炮台

**定位：**建立短时火力支点，让玩家在移动、处理机关时获得额外输出。

**现行规则：**在施放位置附近部署炮台，持续 8 秒，冷却 15 秒。炮台选择距离自身最近的敌人，弹丸基础伤害 22，射击间隔 0.22 秒。当前没有额外最大索敌距离筛选。

无敌人时不射击，但持续时间仍正常减少；之后进入场中的敌人可以成为目标。炮台不会跟随玩家移动，换关时清除。炮台不继承玩家枪械的穿透、散布和扫描增伤。

**视觉与 UI 要求：**部署时出现地面网格与短暂成型动画，炮台可见转向和枪口。持续时间结束后明确消散，避免误认作永久场景机关。

#### 3.4.5 侦察兵：弱点扫描

**定位：**以更高机动和可频繁施放的标记强化，换取稳定的目标处理能力。

**现行规则：**施放瞬间扫描半径 14 个世界单位内已经存在的敌人，标记持续 6 秒，技能冷却 **6 秒**。携带枪械命中标记敌人时，伤害乘 1.5；可标记 Boss。

具体判定：

1. 扫描是一次取样，不是持续六秒的自动搜索领域。
2. 被标记敌人离开扫描半径后，标记保持到期。
3. 扫描之后生成的敌人不自动获得标记，需要下一次扫描。
4. 无敌人时允许施放，仍进入六秒冷却。
5. 到第六秒时，上一轮效果到期且下一次扫描可用；持续时间与冷却相同不代表自动重施。
6. 技能不位移、不重置冲刺、不提供无敌；炮台伤害不享受标记加成。

**数值示例：**无强化时步枪每弹 16，命中标记目标为 24；狙击枪每弹 100，命中标记目标为 150。每一步伤害取整规则见 F06。

**视觉与 UI 要求：**紫色雷达波表示施放范围，被标记敌人出现跟随锁定框。显示“标记 N / 枪械伤害 +50% / 剩余 X 秒”。标记数为零时仍显示技能已施放，避免玩家误以为按键没有响应。

### 3.5 枪械（F05）

#### 3.5.1 共通规则

五类枪械均在局外选择，局内只能使用选定类别。数字键与滚轮不得在战斗中切枪；数字键 1—3 只在关间补给界面用于选择模块。

当前采用无限弹药，不设计装填动作、弹匣库存或子弹拾取。射击节奏来自射击间隔、空间位置和机枪热量，UI 不应显示无意义的“30/无限”弹匣数。

| 枪械 | 基础单弹伤害 | 基础弹丸数/枪口 | 间隔 | 弹速 | 弹丸寿命 | 特性与取舍 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 脉冲步枪 | 16 | 1 | 0.145 秒 | 28 | 1.5 秒 | 无随机散布，输出稳定；适合中距离持续瞄准 |
| 裂片霰弹 | 13 | 7 | 0.65 秒 | 22 | 0.55 秒 | 扇形发射，相邻弹丸基础角度间隔 7°；近距离多弹命中，远处伤害下降 |
| 磁轨狙击枪 | 100 | 1 | 1.05 秒 | 55 | 1.6 秒 | 高速、穿透、单发重击；空枪后的等待长 |
| 重型机枪 | 11 | 1 | 0.085 秒 | 30 | 1.4 秒 | 随机散布参数 4°，连续输出积热；持枪移动更慢 |
| 蜂群冲锋枪 | 8 | 1 | 0.065 秒 | 23 | 0.72 秒 | 随机散布参数 9°，高频射击；有效命中更依赖接近目标 |

弹速单位为世界单位/秒。弹速乘寿命只代表无命中时的理论最大飞行距离，不等同于实际有效射程；尤其霰弹和冲锋枪还受散布与命中率影响。

#### 3.5.2 霰弹衰减

按弹丸累计飞行距离计算，伤害系数从距离 0 时的 1，线性下降到距离 12 时的 0.25，并钳制在此区间。每枚弹丸独立计算命中与伤害，不能把“13 × 7”写成每次扣除目标 91 点生命的保证值。

#### 3.5.3 狙击穿透

同一弹丸可以依次命中多个敌人，但对同一个敌人只结算一次。当前玩家弹丸没有平台或墙面的阻挡检测；设计地图时不能默认墙体能为敌人或玩家挡住这些弹丸。

#### 3.5.4 机枪热量

- 每次从一个枪口发射，热量增加 0.065，范围为 0—1。
- 热量达到 0.99 后进入过热，停止射击。
- 普通状态每秒散热 0.18；过热状态每秒散热 0.35。
- 热量降到 0.1 或以下解除过热；不是热量稍低于满值就能恢复射击。
- 持续按住射击不阻止散热。双枪使一次齐射积累两个枪口的热量，射速强化也会改变积热速度。
- 进入下一关时热量和过热状态清零。

**设计补充：**过热前用热量条接近满格、散热器升温和声音提示表达压力；过热后明确显示“过热冷却”，不使用与技能冷却相同的图标。

### 3.6 伤害、生存与敌人（F06）

#### 3.6.1 玩家对敌伤害顺序

```text
基础单弹伤害 ×（1 + 弹芯等级 × 0.25）→ 取整
    → 如有距离衰减，乘衰减系数 → 取整
    → 如目标有扫描标记且为玩家枪械，乘 1.5 → 取整
    → 扣除目标生命 → 目标死亡则结算击破、连击与掉落
```

取整采用工程当前规则：恰好位于两个整数中间时取偶数。例如 11 × 1.5 = 16.5，取整为 16。不能用简单的“逢五进一”代替。

弹丸通过前后位置的扫掠线段判定命中，避免高速子弹只检查当前点而越过敌人。非穿透弹命中后销毁；穿透弹记录已命中的对象。

#### 3.6.2 玩家受伤与回复

敌弹命中且玩家不处于无敌时扣除生命，并给予 0.65 秒受伤保护，连击归零。生命最低为 0；到 0 后进入失败结算。当前不设敌人身体接触伤害。

每累计击杀三名敌人生成一个回复物。回复物存活 12 秒，靠近 2.2 单位内吸附，0.6 单位内拾取，回复 15 点生命且不超过上限。切关清除未拾取回复物；玩家没有在关间自动回满生命的规则。

#### 3.6.3 敌人职责

| 类型 | 现有行为 | 对玩家形成的判断 |
| --- | --- | --- |
| 守卫 | 接近后单发射击 | 用于建立基础瞄准、移动避弹和击杀节奏 |
| 无人机 | 浮动追踪并射击 | 要求关注上方空间，避免只沿地面瞄准 |
| 重装 | 生命基数更高，三发扇形攻击 | 要求选择绕行、集中火力或穿透路线 |
| 核心守卫 Boss | 悬浮追踪，阶段性扩大弹幕压力 | 要求在输出、回避和技能时机之间取舍 |

动态刷怪现状为：达到刷新时间、已生成数量未达配额、场上敌人数少于 5 时生成；通常在玩家右侧约 13 单位，每第四只改为左侧约 9 单位，并限制在地图范围内。具体配额和间隔来自关卡配置，地图还可摆放可编辑的敌人部署。

**设计补充：**动态出生前增加可识别预警，尤其在攀塔和下行关避免敌人在落点附近突然出现。预警形式、时长和位置需在首关验证后确定，本稿不声称已有完整遭遇脚本。

#### 3.6.4 Boss 阶段

第三关 Boss 基础生命 1250，第八关 2200，再乘难度生命倍率。Boss 基础弹伤 16，再乘难度伤害倍率。

生命不低于一半时每轮五发，基础攻击间隔 1.3 秒；低于一半时每轮九发，基础间隔 0.85 秒。恰好半血不进入低于半血条件。攻击间隔继续受难度影响。

**设计补充：**进入狂暴时使用短暂轮廓变化、标题变化与音效提示，表现不能完全盖住正在飞行的子弹。当前已有阶段判定，完整阶段演出属于表现完善项。

### 3.7 任务与通关判定（F07）

| 目标类型 | 完成条件 | 是否必须清敌 | 完成后的动作 |
| --- | --- | --- | --- |
| 清敌 | 达到生成配额，且场上敌人全部消灭 | 是 | 到达出口，进入补给 |
| 收集 | 拾取当前关卡要求的全部任务道具 | 否 | 到达出口，进入补给 |
| 顺序机关 | 按配置顺序完成所有终端 | 否 | 到达出口，进入补给 |
| Boss + 机关 | 守卫被击败且反应堆机关完成 | 是，完成守卫目标 | 第八关直接胜利结算 |

非终关完成任务后，玩家与出口距离不超过 1.4 单位才结束当前关卡。条件未满足时接近出口，不进入下一关，不把未完成目标静默补齐。

**设计补充的锁定提示：**根据缺失条件显示“仍有敌军”“还缺任务道具 1 件”或“配电未完成”；任务满足后切换为“任务完成，前往传送门”。出口可以在右、左、上方、底层或中部，指引必须读取实际出口位置。

#### 3.7.1 收集规则

靠近任务道具自动拾取，不需要按 E。每件道具只计数一次，拾取后从场景移除。本关总量取自关卡实际配置，不在 UI 写死。退出、重开或切关后，当前关的收集状态按对应新关配置重新建立。

收集进度和击杀进度分开显示。收集完成时，即使仍有敌人存活，也允许前往出口。

#### 3.7.2 顺序机关规则

靠近终端 1.7 单位内按 E 交互。正确时推进一项进度；错误时本轮已完成顺序清零，显示“顺序错误，已重置”。重新从第一步输入，不造成额外生命损失。

第六关当前顺序为 **II → I → III**。顺序来自关卡配置；提示与判定必须读取同一配置。机关全完成后再次交互不回退进度。

**设计补充：**使用终端身份编号、任务提示中的顺序线索、已完成步骤标记组成基础观察解谜。输入错误后短暂显示失败信息，再恢复首步引导。若多个终端交互范围重叠，明确聚焦其中一个并显示其编号，不让一次 E 连续激活多个。

### 3.8 八关内容（F08）

下列任务、数量和出口方向为当前基线；每关的“体验编排”是设计补充，用于明确后续打磨方向，不表示固定遭遇与教学演出均已部署。

| 关卡 | 当前任务与出口 | 体验编排与关键信息 |
| --- | --- | --- |
| 01 霓雨下城 | 清除配额 8 名敌人，右侧出口 | 先提供移动、瞄准与跳跃的安全识别空间；再引入基础交战和 Q 技能；任务完成后教会读取出口指引。第一关优先建立操作信心。 |
| 02 熔炉生产线 | 清除配额 10 名敌人，右侧出口 | 用平台高度和交战距离强化五枪差异；让玩家体会近距离与远距离打法的取舍。工业表现不额外暗示不存在的熔岩伤害。 |
| 03 核心守卫 | 击败基础生命 1250 的 Boss，随后前往出口 | 将技能留给输出窗口，注意半血后的弹幕变化；首次正式检查冲刺保护和持续瞄准。 |
| 04 天线高塔 | 收集 1 件天线钥匙，前往顶部出口 | 从横向战斗切换到向上攀登；先识别钥匙与出口的高度关系，再规划平台路线。允许绕开敌人，不误导为全清关。 |
| 05 数据回收 | 收集 3 件数据，返回左侧出口 | 形成出去收集、返回撤离的往返节奏；首件道具后更新 1/3 提示，全部完成后重点提示“返回左侧”。 |
| 06 配电迷阵 | 按 II → I → III 接通三终端，前往中部出口 | 先观察编号和顺序线索，再行动交互；保留错误重试。敌人形成压力，但清敌不替代机关条件。 |
| 07 地下档案 | 向下收集 2 件档案，前往底层左侧出口 | 用下穿平台改变路线阅读方式；在首个需要下穿的位置提醒 S，镜头跟随下降并保证落点可辨。 |
| 08 中枢停机 | 击败基础生命 2200 的守卫，并按提示完成三终端 | 同时管理战斗与机关。双目标任意先后完成；第二项目标达成时立即结算，不要求寻找额外传送门。 |

**关卡通用限制：**

- 任一职业与枪械都必须能够完成八关，不设计只有狙击穿透或某职业技能才能打开的必经路线。
- 道具不得摆在玩家无法到达的位置；出口不得位于仅靠特定技能才能到达的空间。
- 上下路线必须使用实际可站立平台和清晰落点，不以发光装饰代替碰撞提示。
- 任务提示与关卡摆放共同更新。增减道具或终端时，分母与完成判定随配置变化。
- 第八关两项目标只完成一项时继续战斗；不能提前弹胜利，也不能在两项完成后继续等待清场或传送。

### 3.9 关间补给（F09）

第 1—7 关任务完成并到达出口后暂停战斗，打开三选一补给。从五类模块中随机抽取三种，同一页面不重复。选一项后立即生效并进入下一关；不可同时获得两项，没有跳过或刷新候选的现行功能。

| 模块 | 实际作用 | 叠加方式与例子 |
| --- | --- | --- |
| 强化弹芯 | 增加携带枪械伤害 | 基础伤害 ×（1 + 等级 × 25%），不是每次在上次结果上再乘 1.25 |
| 高速供弹 | 提高射击频率 | 间隔 = 基础间隔 ÷（1 + 等级 × 18%），两级为除以 1.36 |
| 分裂弹道 | 每枪口增加两枚弹丸 | 基础弹丸数 + 等级 × 2；不更换枪械，双枪分别生效 |
| 装甲修复 | 最大生命 +25，立即回复 50 | 先提高上限再回复，回复后不超过新上限 |
| 机动冷却 | 当前冲刺冷却乘 0.8，立即回复 20 | 多次相乘；不减少 Q 技能冷却 |

下一关保留当前生命、最大生命、积分、击破及本局强化；清理场上子弹、敌人、回复物、任务物和技能实体，再建立新关卡。除模块明确的回复外，不自动回满生命。第八关后没有补给页面。

**设计补充：**模块卡显示选择前后的实际变化，例如“冲刺冷却 1.35 → 1.08 秒”。满血时选择恢复模块仍可生效，不能把治疗溢出表现为额外护盾。

### 3.10 计分、暂停、失败与胜利（F10）

#### 3.10.1 计分

连续击杀刷新 3.5 秒连击窗口；超时或受伤中断连击。每次击杀得分为 `100 × min(当前连击数, 10)`，积分倍率最高十倍。最高连击可继续记录，不因积分倍率到十而停止统计。

最高分在本局终结时写入本机纪录。当前没有按难度分开的排行榜；界面不能暗示不同难度成绩有独立榜单。

#### 3.10.2 暂停

战斗中按 Esc 暂停，或切走游戏窗口时自动暂停。暂停冻结战斗推进、弹丸、技能持续与冷却。点击继续或按 Esc 恢复；不能借暂停持续获得回血、散热或技能刷新。

**设计补充：**从暂停返回首页前弹出丢失本局进度的确认。取消回到暂停，确认后清空本局并进入首页；不恢复到战斗中再打开确认窗。

#### 3.10.3 失败

生命降到 0 后，本局进入失败状态，停止后续战斗扣血和任务推进，保存最高纪录并显示结算。不能通过同一帧晚到的回复掉落把已经失败的一局重新激活。

按 R 或点击“重新出击”沿用当前三项配置，从第一关重开；清空本局升级和计分。按 Esc 或点击“返回首页”回首页，允许重新配置。

#### 3.10.4 胜利

第八关守卫被击败、反应堆机关完成，两条件同时成立时进入胜利，无需走到特定位置。无论先完成哪一项，结果一致。终局后停止敌人攻击与炮台输出，清理在途子弹，不触发第九关。

结算展示结果、积分、击破、最高连击、职业、枪械、难度、用时和最高纪录。**设计补充：**胜利时强化“八区任务完成”的结束感，失败时补充失败区域，便于玩家理解进度。

当前只保存最高分，不保存进行中的战役。刷新网页、关闭程序后不能继续当前一局，界面不出现“继续上次冒险”等不存在的入口。

### 3.11 人工配置要求（F11）

关卡用 Unity Prefab 编辑平台、出生点、出口、道具、终端与敌人部署；战斗数值由 `Balance.asset` 配置，战役与美术引用由 `Campaign.asset` 管理。常用参数必须在编辑器中可读可改。

出击介绍、技能说明与任务数量应从同一配置读取，避免改了数值却保留旧文案。布局或资源经人工调整后，普通运行和构建不得自动生成并覆盖人工成果。

## 四、交互 UI 设计

### 4.1 信息架构与页面流转

页面编号用于与功能设计对应。以下布局是本稿交互方案，示意元素顺序与主次关系，不代表现有界面已完成逐像素改版。

```text
U01 首页
  └─ 开始游戏 → U02 难度 → U03 职业 → U04 枪械
                   ↑ 返回       ↑ 返回       │ 确认出击
                   └────────────┴────────────┘
                                             ↓
                                       U05 战斗 HUD
                                      /       |       \
                          Esc / 失焦 /        |        \ 生命为零
                                  ↓          |         ↓
                              U08 暂停       |      U10 失败
                              │继续          |         │
                              └→ 战斗        |         ├─ R：沿用配置重开
                                             |         └─ Esc：回首页
                  第 1—7 关达标并到出口 ──────┤
                              ↓              |
                          U07 补给           | 第八关双目标完成
                              │选一项        ↓
                              └→ 下一关   U09 胜利
                                            ├─ R：沿用配置重开
                                            └─ Esc：回首页
```

U06 为战斗中的任务、道具、机关与出口反馈，不是切离战斗的独立全屏页面。暂停返回首页的确认弹窗为 U11，属于设计补充。

### 4.2 通用交互与视觉规范

1. 每页只有一个最主要的推进按钮，位置保持一致。选择页的主按钮位于右下，返回位于左下。
2. 选项区分默认、悬停、已选、不可用四种状态。悬停只表示可交互，不覆盖已选状态；已选同时使用边框、勾选标记和“已选择”文字。
3. 返回上一选择页保留结果。点击卡片与点击下一步是两种动作，不能第一次点卡片就立即离开页面。
4. 玩家文案优先使用名称和结果，例如“过热冷却”“还缺 1 件数据”，不显示运行阶段名称、对象编号或内部变量。
5. 使用简体中文为主要信息；英文作为标题或装饰时，不替代必要的中文操作说明。
6. 敌弹、可交互物、危险、已选状态不能只靠红绿颜色区分，同时使用轮廓、文字、编号或图形。
7. 键盘提示只列当前可用操作。选择页有 Enter / Esc，战斗有 Q / E / 冲刺，补给有 1—3，结算有 R / Esc；不能让同一按键在一个状态触发两个动作。
8. 采用现有 1600 × 900 逻辑画布作为排布参考；缩放后保证标题、正文、数字和按钮不相互遮挡。宽高比变化时优先保留安全边距与战斗视野，具体适配需实机确认。
9. 本稿不承诺已有方向键选卡、手柄导航、改键或读屏能力；若增加，应补完整焦点与输入规则。

### 4.4 U02 难度选择

**对应功能：**F01、F02。  
**结构：**顶部步骤条，中部三张难度卡，底部当前配装、返回与下一步。

每张卡必须显示：难度名、一句适合谁、敌人生命、敌人伤害、攻击间隔及“更慢／标准／更快”说明。三卡排列优先支持横向比较，不把参数藏在鼠标悬停内。

| 交互 | 页面响应 |
| --- | --- |
| 点击简单／中等／困难 | 立即更新已选标记和底部摘要，仍停留本页 |
| 点击下一步／Enter | 携带当前难度进入职业页 |
| 点击返回／Esc | 回首页，选择保留 |

页面底部固定说明：“三档难度使用相同关卡、职业与枪械；普通敌人与 Boss 均受难度影响。”

点击职业后更新模型、定位、技能介绍和视觉预览。预览在局外播放，不消耗本局技能、不向战斗场景生成实体。“预览技能特效”允许重复播放。

侦察兵介绍采用如下完整口径：

> 弱点扫描：标记施放时 14 单位内的敌人，持续 6 秒；你的枪械对标记目标伤害提高 50%。冷却 6 秒。可标记 Boss，新生成的敌人需要再次扫描。

### 4.6 U04 枪械选择

**对应功能：**F01、F05。

左侧纵向显示五种枪械及缩略模型，右侧显示所选枪械大图、定位、实际参数和限制。右下主按钮为“确认配置并出击”，不能继续使用笼统的“下一步”。

| 枪械详情的字段 | 表达要求 |
| --- | --- |
| 名称与模型 | 与实际携带资源对应；五类模型比例保留差异 |
| 定位 | 如“中距离稳定输出”“近距离爆发”“远距离穿透” |
| 基础伤害与弹丸 | 霰弹写“单弹 13 × 7 枚”，不只写“伤害 91” |
| 射击间隔 | 秒数保留足够精度，0.065 不能四舍五入成 0.1 |
| 独特机制 | 距离衰减、穿透、过热、散布和移速代价以文字说明 |
| 配装限制 | 固定显示“本局八关仅能使用所选枪械，返回首页后可更换。” |

点击返回或 Esc 回职业页；选枪保留。确认出击后进入第一关，鼠标指针转为战斗准星，旧菜单点击不得继续被解释为再次出击。

### 4.7 U05 战斗 HUD

**对应功能：**F03—F10。

```text
┌─────────────────────────────────────────────────────────┐
│ 难度  装甲 75/100      04 / 天线高塔      积分  暂停提示 │
│                                                         │
│ 主任务：取得天线钥匙后到达顶部                           │
│ 钥匙 0/1                  [Boss 关显示 Boss 血条]       │
│                                                         │
│             保持中央战斗与落点视野                      │
│                      玩家 / 敌人 / 任务物                │
│                           ↑ 出口方向                    │
│                                                         │
│ 操作提示    携带枪械    Q 技能状态    冲刺状态   机枪热量 │
└─────────────────────────────────────────────────────────┘
```

**信息层级：**

- 最高优先级：生命、即时危险、准星、可交互提示。
- 第二优先级：主任务、当前进度、技能是否可用、机枪是否过热。
- 第三优先级：积分、最高连击、通用操作提示。它们不能挤压任务文字或角色周围视野。

现有 HUD 已显示生命、任务、武器、技能、分数等。示意图中的布局重排、独立冲刺状态与下述提示细化属于设计补充。

#### 4.7.1 技能状态

| 状态 | 显示与响应 |
| --- | --- |
| 就绪 | 图标完整，显示“Q / 就绪” |
| 持续中且冷却未结束 | 分别显示“效果剩余”和“冷却剩余”，不能合并为一个不明倒计时 |
| 效果结束、仍在冷却 | 只保留冷却信息，图标降亮度 |
| 冷却中按 Q | 不施放；设计补充为一次短促反馈，不反复弹大提示 |
| 扫描无目标 | 显示“已扫描 / 标记 0”，继续显示持续与冷却，避免误认输入失败 |

#### 4.7.2 武器与热量

常驻显示当前枪械名称与“本局固定”。仅机枪显示热量百分比和过热状态。过热锁定与技能未就绪应使用不同文字和位置，不能让玩家误判 Q 导致武器失灵。

武器跟随瞄准的旋转不得影响 HUD；移动准星到左上、左下及角色正上方时，模型仍围绕角色持枪点运动。

### 4.8 U06 任务、拾取、机关与出口反馈

**对应功能：**F07、F08。

#### 4.8.1 任务文字

| 关卡状态 | 玩家文案示例 |
| --- | --- |
| 清敌未完成 | 清除敌军，再进入传送门。 |
| 高塔收集未完成 | 天线钥匙 0/1 · 取得钥匙后前往顶部。 |
| 数据收集完成 | 数据 3/3 · 返回左侧传送门。 |
| 机关部分完成 | 配电进度 1/3 · 按提示顺序接通终端。 |
| 终关仅守卫完成 | 守卫已击败 · 关闭反应堆后完成任务。 |
| 终关仅机关完成 | 反应堆已关闭 · 击败守卫后完成任务。 |

任务描述、进度与完成判定必须一致。收集关仍可显示剩余敌人作为辅助信息，但不得把它排成必须清除的主任务。

#### 4.8.2 道具反馈

任务物使用与普通回复物不同的图形。拾取后移除物件、更新计数、播放一次反馈；最后一件取得后更新出口目标。回复物则显示真实生命增加，不能增加任务数量。

#### 4.8.3 机关状态

| 状态 | 反馈要求 |
| --- | --- |
| 范围外 | 保留编号和状态轮廓，不显示可按 E 的假提示 |
| 范围内、可交互 | 显示“E 操作终端 II”等带对象名的提示 |
| 正确输入 | 对应终端亮起完成标记，进度增加一格 |
| 错误输入 | 显示“顺序错误，已重置”，此前步骤回到未接通 |
| 全部完成 | 显示“配电已接通”或“反应堆已关闭”；不再因重复按 E 回退 |

正确状态同时使用编号旁的勾选或连线，错误状态同时使用文字，避免只用绿灯和红灯。

#### 4.8.4 出口指引

未完成时出口表现为锁定，并给出缺失条件。完成后出口亮起，显示实际方向；出口在镜头外时使用边缘箭头，在镜头内时使用门附近标识。箭头指向实际坐标，不固定朝右。

第八关不显示“去传送门”作为胜利条件；双目标完成后直接移交结算页。

### 4.9 U07 关间补给

**对应功能：**F09。  
**进入：**第 1—7 关达成目标并到达出口；战斗冻结。  
**离开：**选择一张模块卡，进入下一关。

页面显示“区域完成”“选择一个补给模块”，三张候选卡各包含模块名、效果、当前到选择后的变化和独立选择按钮。数字键 1／2／3 与卡片位置一一对应。

选择后只提交一次，立即关闭补给；同帧第二次按键不能再获得模块。没有返回上一关、撤销选择、免费刷新等入口。文案应使用“本局生效，可叠加”，不使用“永久解锁”。

### 4.10 U08 暂停与 U11 返回确认

**对应功能：**F10。

暂停层盖在当前战场上，主按钮“继续突围”，次按钮“返回首页”，并显示“切换窗口会自动暂停”。背景保持可辨但不继续运动。按 Esc 继续，不能把同一次 Esc 同时用于关闭其他弹窗和恢复战斗。

**U11 设计补充文案：**

> 返回首页？当前这局的关卡进度与强化将被清空，最高纪录保留。

按钮为“继续本局”和“确认返回”。默认安全焦点放在“继续本局”；弹窗内 Esc 取消返回，回到暂停层，不直接进入战斗。确认后清理本局状态并回 U01。

### 4.11 U09 胜利结算与 U10 失败结算

**对应功能：**F10。两页共用信息布局，通过标题、说明和视觉反馈区分结果。

| 内容 | 胜利页 | 失败页 |
| --- | --- | --- |
| 主标题 | 通关成功 · 中枢已关闭 | 突围失败 · 机体损毁 |
| 结果说明 | 已完成全部 8 个区域，守卫击败，反应堆停机 | 装甲耗尽，本次行动结束；补充失败区域为设计补充 |
| 数据 | 积分、击破、最高连击、配装、难度、用时、最高纪录 | 同左 |
| 主按钮 | 重新出击 [R] | 重新出击 [R] |
| 次按钮 | 返回首页 [Esc] | 返回首页 [Esc] |

“重新出击”沿用配置但重新开始第一关，不代表从当前关复活。“返回首页”允许重新选择职业和枪械。新纪录标识仅在确实刷新最高分时出现，属于设计补充。

胜利页不出现“下一关”，不再弹出补给。结果页出现后，旧子弹、场上剩余特效或鼠标点击不得重新触发战斗判定。

### 4.12 关键流程核对

本稿评审优先核对以下场景，确认规则和界面讲的是同一件事：

1. 逐页选好三项配置，再逐页返回修改难度，其他选择不丢失；确认出击后局内不能切枪。
2. 侦察兵空放扫描仍进入六秒冷却；标记旧敌人、新生成敌人和离开范围敌人的表现符合 F04。
3. 医疗兵满血施放时得到保护但不虚增生命；工程炮台无敌人时不停止寿命倒计时。
4. 机枪双枪过载时两个枪口正确发弹并共同积热；过热锁定和解除条件与热量显示一致。
5. 第四、五、七关收集完成后可以不清敌通关；第六关错误顺序清零后可重新完成。
6. 出口在顶部、左侧、底层和中部时指引正确；玩家未达到门前时不提前切关。
7. 第八关分别测试“先杀守卫”“先关反应堆”，均在第二条件完成时直接进入胜利。
8. 暂停不推进技能、热量和敌弹；返回首页确认取消后仍保留本局。
9. 胜利或失败后按 R，全部本局强化清空并从第一关开始；关闭再打开游戏不宣称可继续中断进度。
