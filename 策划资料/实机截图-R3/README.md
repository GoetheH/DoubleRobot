# R3 策划案实机截图

采集日期：2026-10-17。来源为本机现有《霓虹突围》Windows 试玩版，本轮未重新构建游戏。15 张图已嵌入 [Excel 图文策划案](../../outputs/neon-gdd-r3-20261017/霓虹突围-游戏设计策划案.xlsx) 的对应 UI 条目。

## 采集方式

- 13 张 PNG：重新运行游戏已有的 `--neon-smoke` 验证流程，由 Unity 实际渲染并截图。菜单由验证流程切换；技能、关卡、机关与终关场景含预设位置、敌人、进度或计时，画面冻结以便观察。它们展示当前 UI，不代表人工打完八关的过程。
- `manual-pause.jpg`：正常经过首页、难度、职业、枪械选择后进入第一关，按 Esc 暂停并捕获窗口。
- `manual-defeat.jpg`：恢复第一关后不攻击，受到敌弹伤害直至失败，再捕获结算窗口。捕获后游戏已返回首页。

图片保留原始画面，包括试用标识、原有文案与两张窗口截图的标题栏。未合成新增按钮、修改数值或重画 UI。工作簿内仅按原比例缩放。

## 阅读限制

胜利图的用时 00:00、击破 1，以及部分战斗图额外的敌人计数，来自验证预设，不是自然战役成绩。机关图为预设的部分完成和全部完成状态。

MD 中的返回首页确认、模块前后实际数值对比、HUD 重排、独立冲刺状态和提示细化仍属于设计补充。当前截图仅作现状对照，没有把未实现方案冒充成游戏画面。

`截图清单.json` 记录每张图的编号、UI 对应位置、尺寸、采集方式及 SHA-256。`runtime-validation.txt` 是本次重新运行验证流程产生的原始报告，结果为 PASS；验证流程的含义与范围以报告和源码为准。
